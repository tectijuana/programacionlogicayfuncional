# Anexo — Bitácora de uso de LLM

## Uso de inteligencia artificial

Para la elaboración de esta investigación se utilizó un modelo de lenguaje (LLM) como herramienta de apoyo para comprender los conceptos de currificación y aplicación parcial, encontrar ejemplos y organizar la información necesaria para desarrollar el documento.

## Prompt utilizado

> “Ocupo hacer una investigación sobre el tema de Currificación y aplicación parcial en programación funcional. Necesito una introducción, explicación técnica y ejemplos que permitan comprender la diferencia entre ambos conceptos.”

Posteriormente se realizaron consultas adicionales para verificar definiciones, diferencias y ejemplos relacionados con Haskell y Python.

Nota: solo se anotaron ejemplos utilizando HASKELL.

## Resultados obtenidos

El LLM ayudó principalmente a identificar la diferencia entre ambos conceptos. 

Se encontró que la currificación consiste en transformar una función de varios argumentos en una secuencia de funciones que reciben un argumento a la vez, mientras que la aplicación parcial permite fijar algunos argumentos de una función para obtener otra función con menos argumentos.
También ayudó a generar ejemplos sencillos en Haskell y Python para relacionar la explicación teórica con situaciones prácticas.

## Reflexión crítica

El uso del LLM fue útil principalmente para comprender conceptos que inicialmente podían resultar confusos, especialmente la diferencia entre currificación y aplicación parcial.

Una de las ventajas fue poder solicitar ejemplos sencillos y después utilizar esos ejemplos para entender cómo una función puede recibir argumentos progresivamente y cómo se puede crear una función especializada a partir de otra.

Sin embargo, también se identificó que las respuestas generadas por un LLM pueden contener errores. Por ejemplo, durante la revisión se encontró un problema en el orden de los parámetros de una función de descuentos. Si el ejemplo se hubiera utilizado directamente sin revisarlo, podría haber provocado una explicación incorrecta.

También existe el riesgo de que una explicación generada por inteligencia artificial sea demasiado general o simplifique conceptos que técnicamente son más complejos. Por este motivo, fue necesario revisar los ejemplos y contrastar los conceptos con documentación relacionada con Haskell y Python.

En conclusión, el LLM funcionó como una herramienta de apoyo para investigar, organizar y comprender el tema, pero fue necesario revisar críticamente la información obtenida y comprobar que los ejemplos fueran coherentes.
