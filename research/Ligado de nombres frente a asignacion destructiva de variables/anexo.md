# Anexo — Bitácora de uso de LLM

## 1. Introducción

Para la elaboración de la investigación sobre **ligado de nombres frente a asignación destructiva de variables**, se utilizó un modelo de lenguaje (LLM) como herramienta de apoyo para investigar, organizar y redactar parte del contenido.

La IA se utilizó principalmente para obtener una explicación inicial de los conceptos, identificar las diferencias entre ambos temas y organizar la información en una estructura adecuada para el archivo `README.md`.

La información obtenida mediante la IA fue revisada y adaptada antes de incluirse en el trabajo final.

## 2. Prompt inicial

Para comenzar la investigación, se solicitó al modelo de lenguaje que desarrollara información sobre el tema asignado y que utilizara Markdown como formato de salida.

### Prompt utilizado

> "Realiza una investigación sobre el tema de ligado de nombres frente a asignación destructiva de variables. Incluye una explicación clara de los conceptos principales, sus características, diferencias y ejemplos. Presenta toda la información utilizando formato Markdown para poder incorporarla posteriormente a un repositorio de GitHub."

### Resultado obtenido

La IA generó una investigación extensa sobre el **ligado de nombres y la asignación destructiva de variables**, incluyendo conceptos como:

- Ligado de nombres.
- Ligado estático y dinámico.
- Asignación destructiva.
- Diferencias entre ambos conceptos.
- Scope o alcance.
- Asignación única.
- Relación con variables y memoria.
- Conclusiones y referencias.

### Observación

El resultado fue útil para obtener una primera estructura de la investigación, pero era demasiado extenso para las necesidades del trabajo. Contenía muchos apartados que podían resumirse.

---

## 3. Segundo prompt

Después de obtener la primera versión, se solicitó al modelo que preparara el contenido de manera más completa y directamente utilizable en el repositorio.

### Prompt utilizado

> "Organiza y presenta toda la investigación desarrollada anteriormente en un documento completo de formato Markdown, utilizando títulos, subtítulos, tablas, ejemplos de código y una sección de referencias. El contenido debe estar estructurado de manera clara para poder copiarlo y pegarlo directamente en un archivo `README.md` de GitHub."

### Resultado obtenido

La IA entregó nuevamente la investigación en formato Markdown, utilizando títulos, subtítulos, tablas, ejemplos de código y referencias.

Esto facilitó la transferencia del contenido directamente al archivo `README.md` del repositorio de GitHub.

### Problema detectado

La investigación seguía siendo demasiado extensa y tenía una cantidad excesiva de apartados para una investigación académica de este tamaño.

Por este motivo, se solicitó una reducción del contenido.

---

## 4. Tercer prompt

Finalmente, se solicitó reducir y simplificar la estructura para que la investigación fuera más concisa y mantuviera únicamente los aspectos más importantes.

### Prompt utilizado

> "Reduce y sintetiza la investigación anterior. Conserva únicamente los puntos más importantes y relevantes para explicar el ligado de nombres frente a la asignación destructiva de variables. Organiza el contenido en una estructura breve y clara, evitando una cantidad excesiva de apartados, pero manteniendo la información necesaria para comprender el tema."

### Resultado obtenido

La IA redujo la investigación a una estructura más sencilla de aproximadamente siete apartados principales:

1. Introducción.
2. Ligado de nombres.
3. Tipos de ligado.
4. Asignación destructiva.
5. Diferencia entre ambos conceptos.
6. Relación con el alcance.
7. Importancia y conclusión.

### Evaluación

Esta versión fue más adecuada para el trabajo porque conservaba los conceptos principales sin incluir demasiadas secciones.
