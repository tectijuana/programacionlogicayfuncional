# Anexo – Registro de uso de inteligencia artificial

## Registro de uso de IA

Durante la realización de esta actividad se utilizó inteligencia artificial como herramienta de apoyo principalmente para comprender las instrucciones de la actividad, organizar el trabajo dentro de GitHub y resolver dudas sobre el proceso de entrega mediante Pull Request.

### Prompt 1

**Solicitud realizada:**
Se solicitó ayuda para comprender las instrucciones de la actividad y saber qué era lo que se debía entregar en el repositorio de GitHub.

**Resultado obtenido:**
La IA ayudó a identificar los pasos principales de la actividad y explicó de manera sencilla cómo trabajar con el repositorio, el fork, la carpeta de investigación y el Pull Request.

### Prompt 2

**Solicitud realizada:**
Se solicitó ayuda para realizar un fork del repositorio proporcionado por el profesor y continuar el trabajo desde la copia personal.

**Resultado obtenido:**
Se explicó qué era un fork y por qué era necesario trabajar sobre la copia personal del repositorio antes de enviar los cambios mediante un Pull Request.


### Prompt 3

**Solicitud realizada:**
Se solicitó orientación sobre los pasos que faltaban para finalizar la actividad después de terminar la investigación.

**Resultado obtenido:**
La IA indicó que después de guardar los archivos era necesario revisar la estructura del repositorio y posteriormente realizar el Pull Request hacia el repositorio original del profesor.

## Reflexión sobre el uso de IA

La inteligencia artificial fue utilizada principalmente como una herramienta de orientación durante el desarrollo de la actividad. Su mayor utilidad fue explicar de manera sencilla conceptos y procedimientos de GitHub que no se conocían completamente como el fork, los commits, la organización de archivos y el Pull Request. La IA también sirvió como apoyo para organizar la información de la investigación y resolver dudas durante el proceso, sin embargo las indicaciones proporcionadas fueron revisadas antes de realizar cada paso y no se utilizaron las respuestas de manera automática. El uso de esta herramienta permitió comprender mejor el flujo de trabajo de GitHub y completar la actividad de una manera más ordenada. También se tuvo en cuenta que la información proporcionada por una IA puede contener errores, por lo que es importante revisar las fuentes y comprobar las instrucciones antes de utilizarlas.
